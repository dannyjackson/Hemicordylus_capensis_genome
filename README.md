# Genome assembly of *Hemicordylus capensis*

This repository documents a reassembly of the *Hemicordylus capensis* genome. The previous release includes a primary chromosome-level assembly (GCF_027244095.1) and a scaffolded alternate assembly (GCA_027244105.1).

The goal of this project is to produce chromosome-level assemblies for both haplotypes and resolve the pseudoautosomal region of the sex chromosomes.
